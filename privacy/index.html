Privacy

This site does not track you

What this site collects

Nothing, directly. This is a static site (plain HTML/CSS/JS) hosted on GitHub Pages. There is no analytics script, no Plausible/Fathom/GA-style pixel, no cookie banner — because there are no cookies to bank. We chose not to run any visitor-analytics service, so there is no "analytics alternative" in use here at all: no tracking is the alternative.

What GitHub Pages logs

GitHub, as the host, may log standard web server data (IP address, user agent, request timestamps) the way any web host does, per GitHub's privacy statement. This site's owner has no access to that data and does not receive it.

Outbound links

Product links on this site go to Gumroad, YouTube, and news outlets. Once you click through, that destination's own privacy policy applies — this policy only covers this site.

Local storage

This site does not use localStorage, sessionStorage, or any browser storage. Nothing is remembered between visits.

Contact

Questions about this policy: open an issue on the GitHub repository for this site.
