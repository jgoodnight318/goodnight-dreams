## Description (1,180 chars)

You have a job that needs judgement, not just rules: reading documents and pulling out what matters, researching a list of companies, answering support email in your voice, monitoring a site and acting when something changes, turning messy data into a clean report. I build Claude-powered agents and scripts that do that job on a schedule and tell you what they did.

What you get:
• Clean Python (or Node) source with a `.env.example`, README and tests
• The Claude prompt engineered against your real examples, not a generic template
• Scheduling on your machine or server (cron, launchd, or a GitHub Action) so it runs without you
• A daily or per-run summary to Slack or email, with a clear log

I'm a solo developer who runs my own business on autonomous agents: they handle support, analytics, publishing and monitoring around the clock. I build what I run.

Everything uses your own Anthropic API key, so you own the code and the costs (usually cents per run).
